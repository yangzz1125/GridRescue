# GridRescue 参赛组队简报

赛事硬规则（以[赛事官网通知](https://cpipc.acge.org.cn/cw/contestNews/detail/2c90800c8093eef401809d348f8b0653/2c9080189ed9bdb5019ef242c9261327?page=0)为准）：每队 3–6 名学生、专业不限，可跨院校/年级/专业；队长为第一申报人且代表其培养单位；同一学生只能参加 1 队。若含本科生或非全日制研究生，须由全日制研究生担任队长，且相应比例均不高于 50%。每队可配 1–2 名正式指导教师。官网合并口径为报名/资格审核截至 **2026-09-11**；高校执行通知常拆成 **9-09 报名、9-11 资格审核、9-13 作品提交**，建议按 9-09 内部目标倒排；HUST 校内截止若更早，以校内通知为准。

## 一句话招募

华中科技大学电气背景，10 天做出一个可运行的软件作品：**极端天气下配电网故障恢复与低碳保供数字孪生平台**。不做硬件，核心是电气模型、优化决策、可复核证据和现场演示。

## 建议 4 人配置

若当前只有项目负责人，先按 `docs/solo_operator_plan.md` 补 2 名低负担真实队员，再按下面的 4 人配置扩展。核心代码不需要重做。

| 角色 | 负责内容 | 最低交付 |
|---|---|---|
| 电气建模 | case33bw、P/Q潮流、孤岛、热限、CareTask | 1 个灾种场景可解释复现 |
| 优化与实验 | 三种恢复策略、36场景批、CVaR | `experiment_runs.csv`、配对统计 |
| MRV与软件 | factor registry、inventory、verifier、Streamlit | 可下载证据包、health smoke |
| 申报与演示 | 申报书、视频、答辩Q&A、盲审 | 五分钟（目标4分55秒）录屏和最终ZIP |

## 10 天分工

```text
D1：统一题目、赛道、主张边界
D2：冻结case33bw与三类灾种
D3：跑36场景和严格合同样本
D4：完成CVaR风险卡
D5：完成MRV敏感性卡
D6：工作台和视频初版
D7：校内盲审
D8：只修阻断问题
D9：打包、hash、离线备份
D10：彩排和提交
```

## 对外展示的核心指标

- 关键服务恢复率 / 关键 EENS：Care 门；
- 电压、支路热限、孤岛平衡：Physics 门；
- kgCO2 清单、factor 等级、SHA-256、verifier：MRV 门；
- CVaR95 与 failure budget：尾部风险；
- 台风 `normal_anchor → BLOCKED`：诚实失败证据。

## 每位队员必须记住的边界

```text
E类合成工程输入 ≠ 现场测量
SEALED ≠ 第三方核证
same_service_pass=false ≠ 严格同服务减排
```

## 单人主导时的最小分工

| 人员 | 责任 | 最低投入 |
|---|---|---|
| 项目负责人 | 代码、模型、申报书、主讲 | 全流程 |
| 队员 A | 跑 README 命令、核对结果 | 1 次复核 |
| 队员 B | 录屏彩排、指出表达问题 | 1 次彩排 |

报名系统仍需 3–6 名真实学生；AI 负责工程协作，不计入参赛人数。队名、申报书和支撑材料不得出现学校、学院、导师等影响公平的信息。

原创性留痕：赛事官网 2026-06-30 规则解读要求学生团队主导核心创意、关键技术路线和主要解决方案。队员 A/B 的复核、实验记录、彩排意见和代码提交应保留在项目日志中，申报书不要直接挪用导师论文/专利的图表、数据或结论。
