- 审计修复：双向购电失衡、容量边界、持续恢复口径和新目录复算保护均有回归测试。
- 新实验：三灾种基准、36场景、严格/去Care合同扫描及三个公开天气案例已完成，历史证据未覆盖。

- 独立潮流：PYPOWER检查550个可求解分量时段，392个不适用；不代表现场验证。
- 浏览器：1440、1024、390、320px，节点、图标、详情、展开、小时和资格预设通过。
- 当前全量回归85项。最终结果读取 `artifacts/submission_audit_20260907/final_verification.json`，不沿用历史74项或旧九包记录。
- 最终包必须通过逐文件SHA、manifest完整性和解压运行检查；以 `check_submission_ready.py` 当次输出为准，不以ZIP存在为准。

- [ ] 确认队伍3至6人、队长及全体真人队员的资格，AI不能计入人数。
- [ ] 向学校确认报名推荐、资格审核和上传权限均已完成。
- [ ] 核对系统当前截止时间；已获取通知列报名审核9月11日、作品9月13日，任何新通知优先。
- [ ] 将正文内容套入官方最新模板，填写真实贡献、导师、承诺、签字及盖章字段。
- [ ] 按学校/秘书处要求披露AI辅助使用，不虚报自主手写代码、合作单位或现场成果。
- [ ] 检查匿名正文、文件名、PDF属性、PPT、视频、截图和链接中是否暴露学校、学院、导师等身份。
- [ ] 核对所需格式、大小上限、视频时长及第三方数据/素材授权，不把软件ZIP当作所有正式材料。
- [ ] 按 `team_defense_20260907.md` 排练，能解释结果、失败点和边界；按正式要求制作答辩PPT或视频。
- [ ] 在另一台机器解压、安装和演示；上传后核对最终文件、SHA和回执。

## 使用哪个文件

使用 `release/GridRescue_Competition2026_Audit_Submission.zip`，对应SHA文件为 `GridRescue_Competition2026_Audit_Submission_SHA256.txt`。

旧的 `GridRescue_Competition2026_Submission.zip` 仅作历史封存，不能作为本轮最新成果上传。

```powershell
python scripts/check_submission_ready.py --run-extracted-smoke
python -m streamlit run app.py --server.address 127.0.0.1 --server.fileWatcherType none
```

## 统一边界

允许：公开天气与年度官方因子驱动的公开算例仿真；三门推荐资格；服务让步下的清单差异；内部可复算证据；独立静态潮流交叉检查。

当前不支持：严格同服务减排、真实医院救治效果、已部署真实馈线、自动现场控制、灾害概率预测、第三方核证、整体全局最优、CareTask成功率显著提升、获奖保证。
