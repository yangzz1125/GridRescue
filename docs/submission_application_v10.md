# GridRescue“碳韧智网”作品申报书 V10

**版本日期：2026-08-23**  
**V08证据冻结日：2026-08-22**  
**建议主赛道：新型电力系统、储能与氢能**

## 一、项目摘要

GridRescue是一套面向极端天气配电网故障恢复的预案级软件原型。它将生命线服务合同、配电网P/Q物理反馈、恢复资源调度和可复算碳清单放入同一决策链。系统不接受“少供电所以低碳”的捷径：候选方案必须依次通过Care、Physics、MRV三道门，才进入推荐。

## 二、现实问题

暴雨内涝、台风和极端高温会造成多支路故障、资源受限和恢复顺序冲突。单纯最小化EENS可能增加柴油或上级电网排放；单纯追求低碳又可能牺牲普通服务。传统看板通常只展示结果，无法回答：服务是否等价、潮流是否可行、碳数字能否复算。

## 三、核心创新

### 1. 服务合同门

将ICU连续供电、应急手术、冷链和通信等生命线任务表示为带最小功率、时窗、deadline、连续时长、依赖和电压阈值的CareTask。服务不再只是一个静态权重。

### 2. 物理可行性门

恢复候选经过成岛、径向性、P/Q平衡、潮流、电压、支路热限和资源约束校验。缺少成网型电源的孤岛以`BLOCKED/NO_GFM`保留为反例，不进入推荐。

### 3. MRV证据门

每小时活动账、因子快照、kgCO2清单、碳对账、拓扑动作链、行级hash、manifest和seal组成可复算证据包。篡改活动账、因子或动作链后，verifier必须FAIL。

### 4. 受控服务差异而非伪减排

当候选与参考服务不等价时，系统自动设置：

```text
same_service_pass=false
claim_status=controlled_service_budget_inventory_difference
```

界面和材料只展示受控服务预算下的运行碳清单差异，不写严格同服务减排。

## 四、技术实现

- 网络：MATPOWER case33bw，33节点配电网；
- 灾种：暴雨内涝、台风、极端高温；
- 策略：传统顺序恢复、最小失供恢复、碳韧协同恢复；
- 优化：词典序服务锚点、普通服务预算、碳清单差异；
- 物理：平衡三相P/Q径向前推回代潮流与反馈迭代；
- 证据：版本化因子注册表、逐时活动账、MRV verifier；
- 展示：Streamlit评委工作台、三门证据抽屉、冻结回放和NO_GFM反例。

## 五、实验与结果

### V08正式证据

- 3个正式MRV bundle：暴雨、台风、极端高温；
- 每个bundle 17个文件，均Verification PASS；
- 因子等级E类合成工程假设，气体边界CO2，单位kgCO2，时间步长1.0 h；
- V08基线回归：46 passed。

### Wave10 36场景批处理

- 3灾种×3强度×4固定复本，共36个scenario_id；
- 3种策略共108条物理策略行，108/108成功；
- 碳韧协同相对最小失供的配对均值差：EENS +3192.85 kWh，运行清单 −2331.35 kgCO2；
- 关键EENS −15.05 kWh；
- C0/C4分轨：36对，controlled_eligible=36，strict_eligible=0。

上述结果只支持“受控服务预算下的运行碳清单差异”，不支持严格同服务减排。

## 六、软件交付与验证

- 全量测试：61 passed；
- V08三bundle独立verify均PASS；
- 36场景catalog有固定root seed、payload SHA和重放字段；
- 失败manifest保留失败行，不以0填充；
- 七张图由V08正式artifact重绘，含source SHA、run ID和冻结日期；
- 离线pipeline cache保障现场演示冷启动；
- 提交包经过manifest文件hash和ZIP testzip核验。

### Wave11 风险与MRV增强

- CVaR95/失败预算：从36场景回放中同时展示均值、P95、CVaR95和失败率，避免只按平均EENS推荐；
- MRV因子不确定性：固定activity inventory，基于factor registry的uncertainty_pct执行500次确定性LHS，输出kgCO2区间与排名稳定率；
- 两项增强只改变风险排序与证据表达，不改变Care/Physics门，也不改变`same_service_pass=false`的主张边界。

## 七、应用价值

首个落地入口是园区、医院、数据中心或单馈线的离线预案、演练和复盘。系统输出的是可追问的候选方案、服务边界、物理证据和碳清单，而不是未经审批的实时控制命令。接入真实馈线、气象和排放因子后，可沿同一数据卡和MRV schema替换输入并重新核验。

## 八、边界与后续

- 当前数据为E类合成工程输入，不等于现场测量；
- SEALED只表示文件完整性与内部复算，不等于第三方核证；
- Carbon-SOC绩效、GNN/RL、完整MISOCP/AC-OPF和SCADA写回不进入本轮主张；
- 下一阶段做同服务合同下的C0/C4实验、真实天气回放和更大馈线外部效度验证。

## 九、一句话价值

> 我们不是让优化器报一个更低的碳数字，而是规定这个数字在什么服务、物理和证据条件下才有资格被相信。
