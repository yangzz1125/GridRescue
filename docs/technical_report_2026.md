# GridRescue 2026 技术报告

## 1. 系统目标

GridRescue是一套极端天气配电网离线预案与复盘原型。它不直接控制现场设备，而是生成候选恢复计划，并回答三个问题：生命线服务是否满足、配电网物理是否可行、碳清单是否可追溯复算。

## 2. 数据模型

`GridModel`保存节点P/Q负荷、DER容量和支路R/X/热限。电气参数来自MATPOWER case33bw；热限、DER、节点类别和CareTask是项目工程假设。`DisasterScenario`保存故障支路、修复时间、逐时负荷/PV输入及来源记录。

公开天气轨道读取固定24小时ERA5响应，经严格时区、单位、连续性和非有限值检查后使用：

- 负荷倍率 = 基础日曲线 + `0.012 × max(T-26, 0)`；
- 光伏倍率 = `clip(短波辐射 / 1000 × 0.85, 0, 1)`；
- 电力因子 = 2023全国电力平均0.5306 kgCO2/kWh，24小时固定。

转换系数是透明工程假设，不是负荷或光伏实测拟合。

## 3. 恢复计划

传统策略按输入顺序修复且不闭合联络线。最小失供策略按下游负荷/修复时长排序并贪心闭合不成环联络线。碳韧策略固定与最小失供相同的恢复拓扑，以避免拓扑差异冒充调度碳优势。

联络线每次闭合均执行NetworkX森林检查。该方法是确定性启发式，不是完整开关与修复队伍联合优化。

## 4. 资源调度

CVXPY模型按小时和电气连通分量优化服务负荷、上级电网、柴油、光伏、储能充放电和弃光。主要约束包括：

- 每节点服务功率不超过需求；
- 每连通分量有功平衡；
- 无成网资源孤岛不得由跟网型光伏独立带电；
- 柴油、储能功率和SOC上下限；
- 储能递推 `SOC[t+1]=SOC[t]+η·charge-discharge/η`；
- 非根孤岛无功需求不超过工程无功能力近似；
- 医院、其他关键和普通负荷EENS上限；
- CareTask在规定节点和时窗的最低功率约束。

服务锚点依次最小化医院、其他关键、普通EENS，并锁定前一级最优值。碳候选在服务上限内最小化运行清单。求解器为CLARABEL。

## 5. 物理反馈

每个候选执行分岛径向前推回代：

1. 由节点净P/Q计算注入电流；
2. 后向累加支路电流；
3. 前向更新节点复电压；
4. 计算支路视在功率、I²R/I²X损耗和热载率；
5. 将损耗及违规分量服务上限反馈给调度，最多8次。

根分量由上级电网平衡；非根分量必须具有柴油或储能成网候选。无资源孤岛保持失供，不注入虚拟slack。物理门要求电压、热限、平衡、潮流收敛和反馈收敛同时满足。

局限：模型为平衡三相径向近似；未建立相不平衡、保护配合、暂态稳定以及每设备完整P²+Q²≤S²曲线。

## 6. CareTask

四项合成任务覆盖ICU/急诊、应急手术、药品冷链和应急通信。任务共享节点时按同时需求求和，避免重复使用同一服务功率。完成条件同时检查功率、电压、连续时长、deadline和依赖。任务参数用于方法演示，不代表临床规范。

## 7. 碳核算与MRV

运行清单：

`CO2 = Σ(grid_kWh[t] × grid_factor[t]) + Σ(diesel_kWh[t] × diesel_factor) + crew_km × vehicle_factor`

主清单不计弃光机会损失，不将恢复电量直接视为减排。每次运行生成输入快照、逐时调度、拓扑状态、活动账、因子快照、排放清单、碳对账、主张门、动作hash链、evidence index和seal。

Verifier检查文件hash、路径边界、记录hash、24小时覆盖、活动与调度值、因子与清单值、外键、能量/排放方程、动作链和终端hash。它不重新求解潮流，SEALED不是数字签名或第三方核证。

## 8. 不确定性与风险

因子敏感性固定活动和原逐时因子，只按注册表中的显式范围进行LHS扰动。同一因子跨策略共享扰动，不同因子使用独立确定性排列。当前20%范围是研究假设，不是官方置信区间。

风险采用均值、P95、经验CVaR95和失败预算。求解、物理、CareTask或反馈不合格均计失败，失败值不填零。

## 9. 软件结构

- `src/gridrescue/`：模型、调度、潮流、合同、统计和MRV；
- `app.py`：Streamlit工作台；
- `scripts/`：数据下载、实验、制图、打包与验证；
- `data/public/`：冻结公开数据和source manifest；
- `artifacts/competition2026/`：本轮机器证据；
- `tests/`：正向、边界和篡改回归。

## 10. 部署边界

产品适用于园区、医院、数据中心和单馈线的离线预案、演练与复盘。生产化需要真实GIS/拓扑、设备参数、保护定值、OMS工单、气象、负荷、DER遥测、排放合同和权限审计。任何现场控制必须经过调度规程与人工批准，不由本原型直接执行。
