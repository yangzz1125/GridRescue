# GridRescue 十天冲刺执行总控

目标：十天内把现有“合成 IEEE-33 + 聚合调度 + 后验 P-only 校验”升级为可申报、可复现的低碳韧性恢复原型。主线只保留：官方 case33 数据、真实天气情景、严格潮流可行性、三目标公平 Pareto、MRV、实验与申报叙事。

| 日 | 当日任务与报告物 | 验收门槛 / 冻结线 |
|---|---|---|
| D1 | 冻结范围、仓库基线、数据字典；输出 data_audit.md。锁定 case33bw 原文件 SHA、33 母线/37 支路、10 MVA/12.66 kV 基值。 | pytest 基线通过；任何后续参数均不得覆盖 canonical 原始表。 |
| D2 | 导入官方 Pd/Qd、R/X、常开 tie、0-based 映射；输出 baseline_import.csv 和逐行差异报告。 | sum Pd=3715 kW、sum Qd=2300 kvar、32 闭合+5 常开、拓扑为树。数据冻结 F1。 |
| D3 | 建立 pandapower 或 MATPOWER 基准潮流对标，输出 bus/branch golden CSV、误差表。 | 正常态收敛；Vm、支路 P/Q、总损耗与 golden 在预设容差内。旧 P-only 仅标 screening。 |
| D4 | 接入真实天气最小集：ERA5/Open-Meteo 历史小时气温、降雨/风、辐照或可审计替代数据；输出 provenance.md、缓存 CSV、情景映射。 | 每个灾害情景均有来源、时间窗、单位、缺失值处理和固定 seed；数据冻结 F2。 |
| D5 | 故障概率/修复时长/负荷-PV 降额由天气驱动；输出 30 个场景及统计图。 | 场景可复跑；故障数、修复时长、PV 降额的边界合理且保存 seed。 |
| D6 | 严格潮流恢复校验：节点 P/Q、DER P/Q/kVA/SOC、支路 MVA/电流、电压和岛内平衡；输出 feasibility.csv。 | 不收敛、P/Q 残差、低压、过载均硬失败；禁止虚拟 slack 吞平衡误差。冻结 F3。 |
| D7 | 公平 Pareto：同一场景、同一资源、同一修复预算下生成低碳/平衡/高韧性点；输出 pareto.csv、ε 值和求解日志。 | 所有点物理可行；无被支配点；EENS、CO2e、成本口径一致。 |
| D8 | MRV：冻结柴油、购电、车辆、弃绿机会成本边界；输出 factor_source.md、逐时碳账本和审计链。 | 每 kgCO2 可追溯到活动量、因子、来源和版本；不把恢复电量直接称为减排。冻结 F4。 |
| D9 | 全量实验：三灾害×三策略×30 Monte Carlo，输出统计、P90/CVaR、敏感性、失败案例。 | 全部批跑无异常；关键结论带置信区间或分位数；失败工况如实保留。 |
| D10 | 申报材料、演示、复现包；输出技术白皮书、5页答辩图、README、命令清单、artifacts manifest。 | 新环境一条命令复跑核心结果；答辩只引用已冻结图表和数据。发布冻结 F5。 |

## 每日站会与冻结纪律
每天 10:00 定任务，18:00 交付一个可打开的报告物和一个可复跑命令。F1 后不改原始网络；F2 后不改天气缓存；F3 后不改潮流口径；F4 后不改碳因子；F5 后只修阻断性错误。任何指标变动必须附输入版本、git commit、seed、运行时间与旧新差异。

## 三人分工
- A 电网模型：D1-D3、D6；负责 case33、单位、潮流、DER/孤岛物理约束和 golden 测试。
- B 风险与优化：D4-D5、D7、D9；负责天气证据、场景、Pareto、公平约束、Monte Carlo/CVaR。
- C 产品与申报：D1 协同、D8-D10；负责 MRV、UI/导出、图表、README、答辩和复现包。
每天 A/B 交叉审阅数据单位与公平性，C 审查所有图表是否可追溯。

## 砍功能顺序
先砍：移动储能车、DRO/MISOCP、三相不平衡、复杂 UI 动画、自动同期并网；再砍：微网黑启动优化，只保留成岛可行性卡片；绝不砍：官方数据、P/Q 潮流硬失败、统一 Pareto 口径、MRV 审计链、复现实验。

## 风险与降级
MATPOWER 不可用则用 pandapower BFSW 并保存版本；两者均不可用则实现 Backward/Forward Sweep，仅对小规模固定工况对标。真实天气 API 失联则使用已下载、带时间戳和来源的缓存，不临时伪造。严格联合优化超时则采用“启发式候选动作 + 潮流硬校验”，并报告可行解而非宣称全局最优。case33 热额定缺官方值时使用独立工程假设表，界面和申报明确标注。任何潮流不收敛或数据缺失的方案从 Pareto 与宣传图剔除，但保留失败日志。
